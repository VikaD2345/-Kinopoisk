### Описание проекта

**КиноКартотека** — веб-приложение для просмотра и управления каталогом фильмов.

Пользователь может просматривать каталог фильмов, использовать поиск и фильтрацию, открывать страницу фильма и получать подробную информацию о нём.

Авторизованные пользователи получают дополнительные возможности взаимодействия с каталогом.

Администратор управляет содержимым системы: добавляет, редактирует и удаляет фильмы, а также взаимодействует с аккаунтами пользователей.

### API и роли

Перед первым запуском примените `database/schema.sql` к базе PostgreSQL. Скрипт создаёт
таблицы `users`, `movie_genres` и `reviews`.

Первого пользователя можно создать через `POST /users`, после чего один раз назначить
ему роль администратора непосредственно в БД:

```sql
UPDATE public.users SET role = 'admin' WHERE email = 'admin@example.com';
```

В текущей версии идентификатор авторизованного пользователя передаётся заголовком
`X-User-Id`. Роль (`guest`, `client` или `admin`) берётся сервером из таблицы `users`.
Запрос без заголовка также считается гостевым. Это простой вариант для разработки; перед публикацией приложения его нужно
заменить полноценной авторизацией по сессии или JWT.

- `guest`: может просматривать фильмы, жанры, связи фильмов с жанрами и отзывы;
- `client`: дополнительно управляет своим профилем и своими отзывами;
- `admin`: управляет фильмами, жанрами и связями жанров, а также видит список пользователей.

Основные ресурсы: `/movies`, `/genres`, `/movie_genres`, `/reviews`, `/users`.
Создание, изменение и удаление фильмов доступны только пользователю с ролью `admin`.
